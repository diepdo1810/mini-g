## Nguyên tắc

- **Ý tưởng ≠ đã duyệt ≠ đang code ≠ Done**. Mọi issue thiết kế mới đều ở trạng thái `IDEA` cho tới khi chủ dự án chốt.
- **Board Markdown là snapshot thủ công**, không tự cập nhật theo issue/PR. Trạng thái thật kiểm tra trực tiếp Issue/PR.
- Board kéo-thả tự đồng bộ cần tạo **GitHub Projects → Board** một lần qua giao diện GitHub. Kết nối ChatGPT hiện tại chưa tạo hay đổi trường `Status` trong GitHub Projects.
- Khi dùng GitHub Projects: đặt tên `Mini-G | Roadmap`, 5 cột `Ideas`, `Planned`, `In Progress`, `Review`, `Done`, import items từ repo `diepdo1810/mini-g`. Chỉ định người triển khai Antigravity qua comment/PR vì Antigravity không phải tài khoản được assign tự động.
